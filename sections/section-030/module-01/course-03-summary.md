# Summary

Requests describe allocation needs, limits constrain allowed usage and namespace policies can default or reject declarations. Measured usage is a different observation from all of those settings.

A rejected quota request and an accepted workload without placement need different corrections. Effective admitted settings and all workload containers must be considered when explaining capacity or enforcement failure.

Resource declarations and policies act at distinct boundaries. Defaults affect admitted values, quota limits namespace demand, scheduling needs a feasible node, and runtime limits constrain actual process consumption.
