# Security Contexts And Application Privilege

This module develops security Contexts And Application Privilege. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Distinguish Pod and container security settings.
- Explain non-root identity, privilege and capabilities.
- Evaluate filesystem access and writable paths.
- Distinguish admission profile checks from runtime isolation.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
