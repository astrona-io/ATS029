# Custom Types And Application Reconciliation

This module develops custom Types And Application Reconciliation. It connects the intended application behavior to declared resources and observed conditions.

## Learning Goals

- Distinguish type registration from controller behavior.
- Read scope, versions and schema of a custom type.
- Interpret desired fields and controller observations.
- Explain prerequisite, permission and finalizer failures.

## Before You Start

Examples describe system behavior. No runtime is required. Read each field or diagnostic name as part of the stated contract.
